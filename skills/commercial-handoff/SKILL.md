# Commercial handoff

Use the validated assessment. Separate facts, unanswered questions and next action. Link the lead ID and input hash so the operator can inspect the source version.

Show the exact stored recipient and message in the approval queue. The operator decides that payload; model recommendations never grant approval. Rejected actions stay rejected. Approved messages enter a local demonstration outbox, which does not send email.
